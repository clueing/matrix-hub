# matrix-hub (自媒体多账号矩阵分发平台)

一款专为自媒体创作者设计的本地私有化多账号矩阵内容分发与定时发布系统。

## 核心特性
- **本地环境隔离**：每个账号独享独立浏览器存储，零串号风险，防封控安全稳定。
- **多平台适配**：首期支持小红书、抖音，预留快手、微信视频号扩展架构。
- **原画质直发**：完全不做二次转码和有损压缩，原样分发用户原始视频。
- **灵活矩阵映射**：支持 1:N（单视频多账号）与 M:N（多视频多账号）分发，支持从文件夹或表格批量建立任务。
- **双重定时机制**：支持创作者中心官方原生定时与本地错峰调度，保护账号权重。
- **人机协同**：Web 端内嵌扫码登录，遇滑块等强风控支持一键呼出本地窗口手动辅助。
- **开箱即用**：FastAPI + SQLite + Vue 3 架构，零外部中间件，支持 Windows 一键启动。
